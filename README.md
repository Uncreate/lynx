# Lynx

Lynx is a locally hostable, open-source orchestration and cognition
project built around evidence-backed temporal knowledge, bounded
autonomy, expert delegation, deterministic governance, verification,
privacy, and accountable provenance.

**Phase 1 is complete:** behavioral/governance design is frozen at
**Lynx Constitution v0.2** as the implementation baseline.

**Phase 2 begins with repository inspection and a gap analysis. Do not
treat the current chat-router prototype as the target architecture.**
